# FogVault backup

Bounded age/v1 export and encrypted import staging for the FogVault 0.1.0 candidate.
The default native package retains backup support. The age and localization crates use distinct
FogVault registry names, original Rust library aliases, and original upstream versions.
See upstream/provenance.json and upstream/provenance.json for retained sources, patches and licenses.
Packaging is not independent security approval.
